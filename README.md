# Zio TV via livetgtv

Fresh IPTV playlists generated from the public [livetgtv API](https://livetgtv.lovable.app/docs) and refreshed every two hours.

[Open website](https://cybermanxd.github.io/zio-tv-via-livetgtv/) · [Choose a playlist](https://cybermanxd.github.io/zio-tv-via-livetgtv/#playlists) · [Player support](https://cybermanxd.github.io/zio-tv-via-livetgtv/#support)

The website is a dependency-free, frontend-only playlist index with an interactive CSS 3D television. It does not play streams or request channel media.

## Playlists

| Playlist | File | Contents |
|---|---|---|
| English | `english.m3u` | Channels in the API English category |
| Hindi | `hindi.m3u` | Hindi and general Indian channels selected by language filters |
| All channels | `all.m3u` | The complete catalog |
| Kids Hindi | `kids-hindi.m3u` | A curated Hindi kids lineup |
| Custom | `custom.m3u` | Kids, infotainment, Colors Infinity, and Animax |

Open the [website](https://cybermanxd.github.io/zio-tv-via-livetgtv/) to select and copy a permanent playlist URL.

## Quick start

### Hosted playlists

1. Open the website.
2. Select a playlist.
3. Copy its URL.
4. Add the URL to TiviMate, OTT Navigator, or Kodi.

The hosted files are regenerated by GitHub Actions every two hours. Playback requires an Indian IP.

### Local relay

For always-current tokens, CORS support, or clients that need relayed requests, run the local server:

```bash
node src/index.js serve
```

The command prints playlist URLs for devices on the same network. The relay forwards only signed JioTV CDN paths and is not a general-purpose proxy.

### Generate static files

```bash
node src/index.js generate
```

Generated playlists and the website are written to `playlists/` by default.

### Inspect the catalog

```bash
node src/index.js list
```

## Player support

The streams use MPEG-DASH with ClearKey metadata and signed segment requests. A compatible player must read the playlist metadata and forward the required headers.

| Player | Support | Notes |
|---|:---:|---|
| TiviMate | Yes | Recommended for Android TV |
| OTT Navigator | Yes | Reads ClearKey metadata and segment headers |
| Kodi with InputStream Adaptive | Yes | Works with the generated metadata |
| Sparkle or Shaka | Conditional | Use the relay when browser request headers cannot be set |
| Televizo | Limited | Video segments may fail because required headers are not forwarded |
| PotPlayer | No | Does not support the required ClearKey workflow |
| VLC | No | Does not support ClearKey DASH playback |

The website itself never attempts playback.

## How it works

```text
livetgtv API
    ↓
channel catalog and resolved stream metadata
    ↓
playlist filters and category ordering
    ↓
M3U files with ClearKey and request headers
    ↓
GitHub Pages or the local relay
    ↓
supported IPTV player
```

The project formats data returned by the public API. It does not include channels, media, credentials, or a DRM bypass.

## GitHub Pages

The workflow in `.github/workflows/update-playlists.yml` performs the complete hosted deployment:

1. Fetch the repository.
2. Generate all five playlists and the static website.
3. Write `playlists/LAST_UPDATED.txt`.
4. Commit changed generated files.
5. Deploy the `playlists/` directory to GitHub Pages.

GitHub Pages is static hosting. It cannot execute the Node.js relay. Hosted playlists therefore use direct player header syntax unless `ZIO_PROXY_BASE` points to a separately deployed HTTPS relay.

## Configuration

| Variable | Default | Purpose |
|---|---|---|
| `ZIO_OUT_DIR` | `./playlists` | Static generation output |
| `ZIO_PORT` | `8888` | Local server port |
| `ZIO_TTL_MS` | `300000` | Local server cache lifetime |
| `ZIO_INTERVAL_MS` | `1800000` | Watch mode refresh interval |
| `ZIO_CONCURRENCY` | `8` | Concurrent API resolutions |
| `ZIO_PROXY_BASE` | Empty | Public relay base URL embedded in generated playlists |
| `ZIO_API_BASE` | `https://livetgtv.lovable.app/api/public` | Public API base URL |
| `ZIO_EPG_URL` | `https://avkb.short.gy/jioepg.xml.gz` | XMLTV guide URL |

## Development

Requirements:

- Node.js 18 or newer
- An Indian network location for playback testing

Useful commands:

```bash
npm run generate
npm run serve
npm run list
node src/watch.js
```

Windows helper scripts are available in `scripts/`:

- `generate.bat`
- `serve.bat`
- `watch.bat`
- `install-task.ps1`

The landing page is generated by `src/pages-index.js`. It uses inline HTML, CSS, and JavaScript so forks and custom GitHub Pages domains do not need asset path configuration or a frontend build step.

## Channel selection and order

There is no dedicated Hindi category in the upstream API. The Hindi playlist includes channels that explicitly identify as Hindi and general Indian categories that do not identify as another language.

The Kids Hindi playlist uses pinned channel IDs because the upstream category data does not include every relevant channel.

Most playlists follow this category order:

```text
Entertainment
Kids
Infotainment
Lifestyle
Movies
Music
Sports
News
Business News
Devotional
Educational
Other categories alphabetically
```

Selection rules and ordering can be changed in `src/playlists.config.js`.

## Limitations

- Playback is geo-restricted to India.
- Stream tokens and keys expire, so playlists must be regenerated regularly.
- A player must support MPEG-DASH, ClearKey metadata, and required request headers.
- GitHub-hosted files cannot provide the runtime relay.
- Browser playback is intentionally not part of the website.
